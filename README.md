# 🌦️ SkyCast — Weather Dashboard

SkyCast is a modern and responsive weather dashboard built using HTML, CSS, and JavaScript.

It provides a clean interface for viewing weather information such as temperature, humidity, wind speed, visibility, and weather conditions.

## ✨ Features

- 🌡️ Temperature display
- 💧 Humidity information
- 💨 Wind speed
- 👁️ Visibility
- 🌤️ Weather condition display
- 📅 5-day forecast UI
- 🌅 Sunrise and sunset information
- 🔍 City search
- 📱 Responsive design
- 🌙 Modern dark/neon interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
